5. SKILL 4: ZERO-HALLUCINATION CONTENT STANDARD (context/skill4.md)
================================================================================
Goal & Philosophy:
  Absolute zero-fabrication guarantee across every content-generation surface. 
  Missing fields use neutral placeholders, never plausible-sounding invented facts.

What Was Implemented:
  1. Strict Explicit None vs Missing-Key Safety:
     - Audited and updated agent4_export_generator.py, agent4_tailor.py, and 
       _estimate_content_density().
     - Replaced bare .get(key, "") with safe pattern str(profile.get(key) or "") 
       so explicitly None database fields never cause AttributeError: 'NoneType' object has no attribute 'split'.

  2. Neutral Placeholders Catalog Enforced:
     - Missing fields output clearly neutral markers:
         * name: "[Your Name]"
         * title: "[Role Title]"
         * company: "[Company Name]"
         * degree: "[Degree]"
         * field: "[Field of Study]"
         * institution: "[Institution]"
         * description: "[Add description]"
         * skills: "[Add skills]"
     - Zero plausible fake defaults (no "Built scalable backend services", "Bachelor of Science", etc.).

  3. Operator Precedence Bug Fixed in Quality Analysis:
     - Fixed ternary parenthesization in experience text corpus builder:
       (exp.get("description") or "") + " " + (exp.get("title") or "") + " " + 
       (exp.get("company") or "") + " " + 
       (" ".join(exp.get("achievements") or []) if isinstance(exp.get("achievements"), list) else str(exp.get("achievements") or ""))
     - Prevents title, company, and description from being silently dropped when 
       achievements is None or non-list.

  4. PDF Generation Magic Bytes Integrity:
     - Verified ReportLab PDF generator produces genuine binary starting with %PDF- 
       and scales font sizes based on density (never outputs markdown bytes as PDF).

  5. Type Mismatch Resilience:
     - Handled string skills ("Python, SQL"), string experience_years ("3.5"), and 
       string lists gracefully without crash or fabrication.
