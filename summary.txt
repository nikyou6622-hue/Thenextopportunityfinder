1. EXECUTIVE IDENTITY & MISSION
----------------------------------------------------------------------------------------------------
NextOpportunityFind is an end-to-end, 100% free, privacy-first AI Career Acceleration Operating System 
engineered for software engineers, tech students (B.Tech/BE/MCA/BCA), freshers, and career switchers 
in India and globally.

The platform eliminates the primary frictions of modern job seeking:
  1. ATS Black Box: Resumes fail ATS screens due to keyword mismatches or unquantified impact. 
     The platform provides a 5-pillar mathematical score (0-100) and certified export templates.
  2. Fake & Expired Postings: Aggregators spam users with dead links and affiliate redirects. 
     The platform revalidates direct canonical ATS portals (Greenhouse, Lever, Ashby, Workday).
  3. Hallucinatory AI Tools: Generic LLMs invent unearned degrees, companies, and metrics. 
     The platform's zero-hallucination engine is strictly constrained to candidate-verified facts.
  4. Fragmented Tooling: Consolidates job discovery, ATS resume editing, 1-click tailoring, 
     Kanban tracking, interview prep, coding sandboxes, and recruiter outreach into one app.
  5. Privacy Exploitation: Implements India DPDP Act (2023) standards with field-level AES-256 Fernet 
     encryption, 1-click hard cascade purge (Right to Erasure), and zero third-party data selling.

4. MULTI-AGENT ARCHITECTURE & SYSTEM ROLES
----------------------------------------------------------------------------------------------------
The backend is structured into 11 autonomous agents (`backend/app/agents/`):

  1. Agent 1: Resume Parser & ATS Scorer (`agent1_parser.py`)
     - Parses `.pdf`, `.docx`, and `.txt` files.
     - Extracts contact details, 1,500+ tech skills, work experience, projects, and education.
     - Computes 5-pillar mathematical ATS score (0–100). Encrypts text with AES-256 Fernet.

  2. Agent 2: Opportunity Ingestion Engine (`agent2_discovery.py`)
     - Ingests structured opportunities from local databases and verified RSS feeds.

  3. Agent 2B: Big-MNC Career Portal Scanner (`agent2b_mnc_scanner.py`)
     - Career portal scraper for Tier-1 Global Tech & Indian IT Giants (Amazon, Google, Deloitte, etc.).

  4. Agent 2C: India Internships & Entry-Level Scraper (`agent2c_india_internships_scraper.py`)
     - Scrapes tech internships and fresher roles from Indian platforms (Internshala, Unstop).

  5. Agent 2D: Global Remote & Tech Scraper (`agent2d_global_jobs_scraper.py`)
     - Aggregates remote and tech roles from RemoteOK, WeWorkRemotely, and HackerNews Jobs.

  6. Agent 3: Multi-Criteria Match Engine (`agent3_matching.py`)
     - Computes skill overlap, domain match, location match, and semantic similarity score.

  7. Agent 4: Zero-Hallucination Tailor & Exporter (`agent4_tailor.py`, `agent4_export_generator.py`)
     - Generates ATS-optimized PDF, DOCX, and TeX resumes strictly enforcing candidate-verified facts.

  8. Agent 5: Direct ATS Linkout & Source Router (`source_router.py`)
     - Classifies job platforms and resolves raw URLs to official canonical ATS application endpoints.

  9. Agent 6: Recruiter Outreach & Email Drafts (`agent6_batch_email.py`)
     - Generates personalized candidate cold outreach emails for hiring managers and recruiters.

 10. Agent 7: Outcome Intelligence & Diagnostics (`agent7_outcome_intelligence.py`)
     - Tracks application lifecycle events and diagnoses rejection/failure patterns.

 11. Agent 8: Interview Prep & Coding Sandbox (`agent8_interview_prep.py`)
     - Generates company-targeted technical interview prep, LeetCode question banks, and coding challenges.


5. CORE API ENDPOINTS
----------------------------------------------------------------------------------------------------
  - `POST /api/profile/upload`  : Ingests resume file, extracts skills, encrypts text, runs 200-job sync match tier (~22ms match step).
  - `GET  /api/matches`         : Returns matched opportunities sorted by score and skill overlap.
  - `GET  /api/jobs`            : Lists active opportunities with pagination (`page`, `limit`) and search filter.
  - `GET  /api/profile`         : Retrieves active candidate profile data (decrypting PII for authorized sessions).
  - `POST /api/profile/purge`   : Executes DPDP Act Right to Erasure cascade delete across 22 relational tables.
  - `GET  /api/dashboard/metrics`: Computes overview dashboard metrics (applications, response rates, top skills).
